# Ember Moth

A tiny night moth with a lantern on its tail collects drifting embers and jumps over hungry shadows. 2D mobile game (landscape) for Game Development Fundamentals, RK2.

- Engine: Unity 6000.6.0f1, URP 2D, Input System, uGUI
- Screens: Main Menu, HUD, Pause / Game Over (Canvas Scaler 1920x1080, match 1; anchored UI; `SafeArea` panel)
- Controls: on-screen stick + JUMP + pause. In the editor: A/D or arrows, Space, Esc.
- GDD: [docs/GDD.pdf](docs/GDD.pdf)
- Screenshots (16:9, notch phone, tablet): [Screenshots/](Screenshots/)
- Video script: [docs/VIDEO_SCRIPT.md](docs/VIDEO_SCRIPT.md)
- AI usage: [AI_LOG.txt](AI_LOG.txt)

## Run
Open the project in Unity 6000.6.0f1, open `Assets/Scenes/Menu.unity`, press Play.
Scenes and sprites are generated by `Assets/Editor/SceneBuilder.cs` (Tools > Ember Moth > Build All);
`Tools > Ember Moth > Capture Screenshots` renders the three devices.
