# Video script (2-3 min, English, MP4)

**0:00 - Intro (10 s).** "Hi, I'm Ars. This is Ember Moth, a 2D mobile game about a moth with a lantern."

**0:10 - Screens on three devices (60 s).** Open Device Simulator.
For each of: 16:9 phone, notch phone (iPhone 19.5:9), iPad 4:3:
Menu -> press Play -> show the HUD (hearts, score, pause, stick, jump) -> play a few seconds -> Pause -> Resume -> Pause -> Restart -> Pause -> Menu.
Say: "Canvas Scaler is Scale With Screen Size, 1920x1080, match 1. Everything is anchored, and buttons sit inside a SafeArea panel, so nothing goes under the notch. Buttons are at least 120 pixels, text is at least 36."

**1:10 - GDD in one minute (60 s).** Show docs/GDD.pdf. Cover: pitch, 2D landscape, core loop (run, jump, collect, dodge), controls, content, art and sound, MVP, cut list, plan for weeks 9-13, solo roles.

**2:10 - GitHub (40 s).** Show the repository: Unity .gitignore, no Library folder, README. Open Commits (3+ meaningful), then the merged pull request from feature/ui-screens into main.

**2:50 - Outro (10 s).** "Thanks for watching."
